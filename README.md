# P1 Operational Code Repository

## Overview
This repo contains the code necessary to program the P1 by-wire vehicle, record data, and post-process the data.

## Branches
- The **main** branch in this repository is typically the desired branch.
- A **serialreceive** branch exists for debugging the communications coming over serial from the GPS receiver.
- A **digitaltwin** branch contains code that can be run in Simulink or on a Raspberry Pi to mimic the operation of the vehicle.
